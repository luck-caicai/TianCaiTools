# 验证记录

## 1.1.0 开发验证（2026-11-17）

- macOS 27.0.1 / Apple Silicon / Swift 6.4：原生与统一测试入口通过 1,225 项断言。
- 保留原七组 Ctrl 回归检查，新增 Alt+Tab 精确修饰键、正反向选择、按键松开配对、关闭后还原、窗口移除、MRU、双重缓存上限、迟到回调和截图超时准入检查。
- 包含 500 次纯状态选择/取消及释放演练；不安装全局事件钩子，不发送模拟按键，不改剪贴板、系统设置或鼠标。
- 使用合成标题与合成图片渲染原生面板，检查卡片、选中状态、标题、最小化状态及页脚布局；测试窗口已关闭。可用 `zsh scripts/render-panel.sh` 在本机重现，CI 不运行该界面样例。
- 本地构建通过，应用约 635 KB、ZIP 约 343 KB，签名通过严格验证。产物使用 ad-hoc 签名，未公证。
- 更新前稳定版物理内存约 49.9 MiB（峰值约 50.9 MiB）；更新后未获得权限时约 51.9 MiB。窗口清单和实际预览的性能仍待授权后测量，不能据此推断预览峰值。
- 已保留 1.0.1 稳定版备份并安装 1.1.0 试用版。辅助功能与屏幕录制授权待用户完成；真实按键、截图、最小化恢复、500 次面板选择及回收后的内存检查尚待进行。

同名程序的命令行新进程与常驻进程可能处于不同的权限上下文；运行情况优先检查常驻实例的 `--live-status`。只读状态不包含窗口标题或图像。

## 1.0.1 历史验证

## 自动检查

在 macOS 27.0.1、Apple Silicon、Swift 6.4 环境验证：

- `scripts/validate.ps1 -AsJson` 正确发现 `ctrl-switch` 与已有 `image-paste`，分别选择 macOS 和 Windows runner。
- 原生脚本与统一 PowerShell 入口均通过 534 项断言，报告写入 `artifacts/self-test.json`。
- 覆盖七组快捷键、左右 Ctrl、其他按键直通、额外修饰键、Caps Lock、终端例外、长按重复、按键松开配对和关闭后还原。
- 原生脚本与统一入口均能生成 Apple Silicon 的 APP、版本化 ZIP、SHA-256 文件和发布元数据。
- 打包应用通过 `codesign --verify --deep --strict`，ZIP 与发布元数据的大小、SHA-256 一致。

自检只对内存中的键盘事件标记做断言，不安装事件监听器，不修改系统设置、剪贴板或鼠标。

## 本机交互验证

导入仓库前，同版快捷键程序已在实机中授权运行；实际键盘的 Ctrl+A 全选和 Ctrl+F 查找由用户确认生效，菜单栏常驻与系统登录启动已确认。

仓库接入调整了目录、发布品牌和构建流程，键盘转换实现保持一致。新打包产物尚未替换本机正在使用的应用；没有把构建成功当作全部 UI 验证。
