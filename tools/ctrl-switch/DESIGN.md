# Alt+Tab 与按需缩略图

## 模块

- `ShortcutTransformer` 保留原来的七组 Ctrl 转换和终端例外。
- `SwitcherState` 包含无系统副作用的按键状态、固定顺序选择、窗口 MRU、解码图片预算和截图准入规则。
- `EventTapController` 为两项功能共用一个键盘事件入口，监听按下、松开和修饰键变化。只吞掉已匹配的 Tab/Esc 事件，不重映射 Ctrl、Command 或 Option。
- `WindowInventory` 在串行后台队列进行 AX 查询，通过应用及窗口通知刷新；激活使用单独队列，避免等待窗口扫描。AX 调用有短超时与每个应用的扫描时间预算。
- `WindowSwitcherController` 管理一次选择会话、150 毫秒面板延迟和窗口激活。快捷切换不启动截图。
- 面板显示后四个方向键按当前网格选择，所有接管的松开事件保持配对。鼠标悬停使用卡片局部的 NSTrackingArea；比较真实指针位置，忽略静止鼠标引起的初次进入或重建事件。键盘选择重新设置指针基准，避免键鼠交替时回跳。
- 鼠标高亮与键盘确认目标分离。悬停后松开 Alt 会取消并保留原焦点，只有单击才激活悬停窗口；使用方向键或 Tab 重新选择后恢复松开 Alt 确认。
- `SwitcherPanel` 使用非激活 NSPanel、少量 AppKit 视图和 CALayer 展示卡片，取消时不改变前台焦点。
- `WindowPreviewProvider` 负责单次截图、全局单请求、后台小位图复制、会话隔离与有上限的短期缓存。

## 截图与内存

macOS 26+ 使用公开 ScreenCaptureKit 的 `SCScreenshotManager.captureScreenshot`，直接请求最多 480×300 像素的 SDR 输出。只处理选中窗口和当前可见卡片；不创建常驻 SCStream、不取音频、不写截图文件，也没有网络连接。

操作提交完成不代表异步截图完成。真实请求在回调前占据唯一槽位；超过 2 秒后暂停后续提交，槽位仍保留，直到系统实际回调。旧会话的结果不得进入新面板。重新启用预览仅在没有真实请求未完成时清除暂停状态。

输出再复制成小的自有 CGImage，及时放开系统返回的缓冲区。缓存以实际 bytesPerRow×height 计费，同时执行最多 12 张及 8 MiB 两项限制；按最近使用顺序淘汰。图层与缓存共享图像，淘汰、关闭面板与禁用时解除相应引用。30 秒没有新的使用会清理短期缓存。内存压力或锁屏会终止当前截图会话并清理图片。

缓存预算无法限制系统截图服务和绘制图层的全部开销。性能记录必须使用同口径的物理内存，并同时观察 WindowServer 与 replayd。

## 窗口身份与兼容性

通过 AX 获得可切换窗口，通过 CGWindowID 与 ScreenCaptureKit 窗口关联。使用动态查找的 `_AXUIElementGetWindow` 作为小型可选身份桥接；它是未公开的系统符号，缺失时只采用唯一匹配的公开 CG 窗口元数据，无法可靠关联时显示图标。截图后端不使用私有 SkyLight API。

AX 中仍存活的普通窗口、最小化及全屏窗口都加入，不用 CG 的 `isOnscreen` 过滤；该字段只能说明当前可见性，不能用来判断其他桌面窗口是否存在。AXWindows 自身也可能只提供当前桌面的窗口，因此候选合并主窗口、焦点窗口和已见过的 AX 节点，再逐一检查节点是否存活、角色和尺寸是否有效。去重后最多 160 个，仍受每个应用 1 秒扫描预算约束。卡片使用 `AXFullScreen` 显示状态，桌面切换通知仍触发清单刷新。

跨桌面激活通过可选、动态解析的 `_SLPSSetFrontProcessWithOptions` 请求指定 CGWindowID，并使用 AX 设置主窗口、焦点和 Raise。缺失或调用失败时退回公开的应用激活。Space 动画后以有限次数检查应用前台、AX 焦点和目标可见性；目标确实可见且应用在前台后，最多发送一次 `SLPSPostEventRecordTo` 的 make-key 按下/松开对，再检查焦点。记录直接面向目标进程和窗口，两个坐标字段均在窗口内容外；256 字节缓冲区包含系统可能读取的尾部填充，两个边沿保持配对，不移动真实鼠标、不向全局事件流发点击、不点击窗口内容。没有窗口搬移、全屏开关或 Mission Control 设置修改。延迟 Raise 仅限目标应用已在前台时执行，不重复请求切换应用。新的激活、打开下一次选择或禁用功能会推进线程安全的代次，旧回调不再操作焦点。

卡片在 mouseUp 确认，并延迟到该 AppKit 事件返回后结束会话。每次关闭都 orderOut 并 close 面板，清空持有引用；下次展示重新创建面板，避免系统点击前置处理重新显示已经清空卡片的旧窗口。每次呈现有代次，旧点击回调不能操作已经关闭或重新打开的面板。运行诊断同时检查 WindowServer 上属于本进程的浮动面板数量，而不只依赖 NSPanel.isVisible。

ScreenCaptureKit 枚举包含其他桌面，但仍只请求当前卡片的缩略图；缺少图像不影响选择，系统无法截取时保留图标。复杂多显示器、分屏和应用特有的焦点行为需要实际验证。旧 macOS 保留图标模式，不承诺未经实测的截图兼容性。

## 预览中关闭窗口

每张卡片有独立的原生 NSButton。按钮消耗自己的点击，卡片的鼠标区域也排除按钮位置，包括按钮禁用时；确认与关闭分别回调，均检查当前呈现代次。关闭回调先结束选择、销毁预览面板并配对处理已接管的按键释放，再提交指定窗口的关闭请求。

清单仅查询 `AXCloseButton` 及可用状态，不持有其子节点。真正操作在后台队列重新检查窗口 PID、窗口身份、角色和当前关闭按钮，再向该按钮发送一次 `AXPress`。不发送 Command+W、不终止进程、不自动响应保存询问；窗口关闭、取消或保留均以 AX 通知和有限次刷新反映真实状态。沿用已有辅助功能权限，不增加监听器、后台进程或闲置轮询。

关闭后若该窗口出现原生 sheet，则将该窗口及确认界面带到前台，供用户处理；新的选择会取消这次延迟焦点操作。取消保存询问时保留真实窗口，不预测删除。

原应用在显示确认框时可能让 AXPress 超过回复时限。此类不能确认的回复与明确失败分开记录，继续检查原生确认界面及窗口实际状态；既不当作已关闭，也不自动再发一次关闭操作。

## 参考

研究了 [AltTab](https://github.com/lwouis/alt-tab-macos) 固定提交 `950c1a4e749aef53637bf2833b4a09328cdbce8e` 的 WindowCaptureEvents、WindowThumbnails、SwitcherSession、LightImageLayer 及窗口激活路径。借鉴异步更新、分辨率控制、会话内缓存、真实异步请求限流和指定窗口激活的设计；本实现独立编写，未引入其源码、素材、运行时或配置系统。

AltTab 的当前版本已经对全分辨率大图进行按需加载和缓存限制。此工具目前只提供卡片缩略图，以减少对大图和复杂兼容分支的需求。

## 验证边界

无界面自检只验证纯状态，不安装事件监听、不读剪贴板、不改系统设置、不打开窗口。`--exercise-switcher` 是单独的本机演练：真实面板与截图、500 次选择变化，不发送全局键盘事件，也不自动激活用户窗口。真实键盘、权限和焦点仍需要本机单独确认。运行中只读诊断不包含窗口标题、输入内容或截图。
