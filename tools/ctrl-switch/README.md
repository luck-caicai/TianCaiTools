# TianCai快捷键开关

面向 Apple Silicon Mac 的原生菜单栏程序。使用 Swift、AppKit 和系统键盘事件 API，无第三方依赖、无驱动、无主窗口，不占 Dock。

## 为什么开发这个工具

使用的是 macOS，键盘却是 Windows 键盘；或者刚从 Windows 切换到 Mac，还习惯用 Ctrl 复制、粘贴、保存、全选、剪切、查找和撤销。常用操作需要反复想键位、改手势或纠正误按，容易产生停顿，打断原本熟悉的操作节奏。同时使用 Windows 和 Mac 的用户，也会遇到来回适应两套快捷键的问题。

这个工具为这些高频操作提供一个菜单栏开关：开启 `Win Ctrl` 时沿用熟悉的七组 Ctrl 快捷键，关闭后显示 `Mac Ctrl`，恢复 Mac 原生操作。键盘布局以及 Ctrl、Command、Win、Alt 的原有身份和位置保持不变，让日常快捷键操作更连贯。

## 使用

将发布包中的 `CtrlSwitch.app` 放入「应用程序」后打开，右上角会出现一个小开关：开启时显示 `Win Ctrl`，关闭时显示 `Mac Ctrl`。自行编译时应用位于本工具的 `release/CtrlSwitch.app`。

- 单击：开启 Windows 常用快捷键，或恢复 Mac 原生快捷键。绿色为开启，灰色为关闭，橙色为等待授权。
- 右键：独立开关 Alt+Tab 与窗口预览，设置登录时启动，或退出程序。
- 首次运行：在程序打开的系统权限列表中开启 `CtrlSwitch.app`。macOS 27 的页面名称为「设备控制和数据访问」，较早版本称为「辅助功能」，都位于「隐私与安全」中。列表中没有时，点击「＋」选择 `CtrlSwitch.app`。授权后会自动生效。

建议将程序放在「应用程序」文件夹后再授权，之后保持应用的位置不变。程序会记住开关状态；登录时启动默认关闭，可从右键菜单开启。

如果自行重新编译后出现「系统开关已开，但程序仍提示授权」：先在系统权限列表中选中本程序，用「－」移除旧记录，再用「＋」重新添加当前安装的 `/Applications/CtrlSwitch.app`。本机构建采用 ad-hoc 签名，编译变更会更新签名；单纯关闭再开启旧授权可能仍保留旧版本记录。

| 组合键 | 开启后的操作 |
| --- | --- |
| Ctrl+C | 复制（Command+C） |
| Ctrl+V | 粘贴（Command+V） |
| Ctrl+S | 保存（Command+S） |
| Ctrl+A | 全选（Command+A） |
| Ctrl+X | 文本剪切（Command+X） |
| Ctrl+F | 查找（Command+F） |
| Ctrl+Z | 撤销（Command+Z） |

左右 Ctrl 均可使用。Ctrl、Command、Win、Alt 的按键身份和位置保持原样，原有 Command 快捷键照常有效。其他组合键及带 Shift、Option、Command、Fn 的扩展组合保持原样。Caps Lock 状态会保留。

## Alt+Tab 窗口切换

在右键菜单中开启「启用 Alt+Tab 窗口切换」。它与 Win Ctrl / Mac Ctrl 开关独立，关闭 Ctrl 转换后仍可切换窗口。

| 操作 | 效果 |
| --- | --- |
| 快速按 Alt+Tab 后松开 Alt | 切到最近使用的另一个窗口 |
| 按住 Alt 约 150 毫秒 | 显示窗口卡片 |
| 按住 Alt 继续按 Tab | 选择下一个窗口 |
| Alt+Shift+Tab | 反向选择 |
| 面板显示后按 ← / → | 选择前一个 / 后一个窗口 |
| 面板显示后按 ↑ / ↓ | 按卡片行列选择，上下保持相近列位置 |
| 鼠标移到卡片上 | 选中该窗口；松开 Alt 即切换 |
| 松开 Alt | 激活选中窗口；最小化窗口会还原 |
| Esc | 取消，保留原来的窗口焦点 |
| 单击卡片 | 激活对应窗口 |

方向键支持长按连续选择，只在切换面板显示后接管。鼠标停在原地时不会覆盖键盘选择；再次移动到卡片上即可用鼠标选择。面板关闭或 Alt+Tab 功能关闭时，方向键保留原有操作。

左右 Alt（macOS 中的 Option）均可。按键身份不变，其他 Option 组合照常使用。同一应用的多个窗口分别列出；按住 Alt 选择期间顺序固定。

普通窗口以当前桌面为范围；同时列出系统可枚举的最小化窗口。macOS 的辅助功能接口不提供最小化窗口所属桌面，激活时可能由系统切到它原来的桌面。独立全屏、复杂多屏和跨桌面行为尚未完整验证。程序刚启动时需要短暂建立窗口清单；没有可切换窗口时按键直通。

## 窗口截图预览

macOS 26 或更新版本可开启「显示窗口预览」。首次使用，在右键菜单选择「允许窗口截图…」，开启系统的屏幕录制权限；系统要求重新打开时按提示操作。未授权时显示图标和窗口标题，仍可切换窗口。macOS 13–15 使用图标模式。

预览是按需刷新的一张静态缩略图。面板出现后先显示已有图片，再更新选中窗口与可见卡片；快速切换不会等截图。最小化窗口使用已有缩略图，没有时显示图标，不会为了截图将窗口弹出。系统禁止截取的窗口同样使用图标。

- 单张最大 480×300 像素；解码后缓存最多 12 张且合计不超过 8 MiB。
- 全局最多一个真实截图请求。超时后暂停新截图，继续允许窗口切换；关闭再开启预览可在旧请求完成后重试。
- 面板关闭后不再提交截图；短期缓存闲置 30 秒清理。关闭预览、锁屏或发生内存压力时清除本程序持有的图片引用。
- 截图不保存文件、不上传、不采集音频。系统可能显示屏幕捕获状态提示。

8 MiB 是图片缓存上限，不代表程序或系统截图服务的总内存上限。

## 终端快捷键：特别注意

**终端中的 Ctrl+C 用于中断当前命令，不能把它当作复制。已适配的独立终端会自动跳过上述七组转换，保留原有控制操作。**

| 终端操作 | 使用的快捷键 |
| --- | --- |
| 中断当前命令 | Ctrl+C |
| 复制选中的内容 | Command+C |
| 粘贴内容 | Command+V |

这项例外适用于 Terminal、iTerm2、Ghostty、Warp、kitty、Alacritty、WezTerm、WindTerm 等已适配的独立终端，开启 `Win Ctrl` 时也会保留。

**VS Code 等 IDE 的内嵌终端需要手动切到 `Mac Ctrl`。** 当前程序按独立应用识别终端，使用内嵌终端前先点击菜单栏开关关闭转换，保留 Ctrl+C 中断；复制、粘贴继续使用 Command+C / Command+V。

## 其他使用范围

Finder 的文件移动沿用 macOS 原生方式：Command+C 后用 Option+Command+V 移动；本程序不会把 Ctrl+X 改造成文件移动操作。

程序仅在当前登录会话工作。登录界面和系统启用安全输入的区域由 macOS 管理，系统可能暂停键盘事件转换。它不读取剪贴板、不保存按键内容，也没有联网功能。

## 还原与卸载

点击菜单栏开关关闭即可还原；右键退出也会停止转换。程序不会改写系统修饰键设置或其他应用的快捷键配置。

卸载前如曾开启登录时启动，先从右键菜单关闭，再退出并删除 `CtrlSwitch.app`。可在辅助功能设置中移除该应用的授权。

## 开发

构建需要带 macOS 26+ SDK 的 Apple Command Line Tools 或 Xcode；程序可在 macOS 13 或更新版本的 Apple Silicon Mac 上运行，截图预览仅在 macOS 26+ 开放。

```sh
zsh scripts/test.sh
zsh scripts/build.sh
```

构建产物位于本工具的 `release/CtrlSwitch.app` 和 `release/ctrl-switch-<版本>-macos-arm64.zip`，使用 ad-hoc 签名，尚未经过 Apple Developer ID 签名与公证。

```sh
release/CtrlSwitch.app/Contents/MacOS/CtrlSwitch --diagnose
```

`--diagnose` 检查当前启动实例的权限、版本与安装位置。检查常驻进程请用 `--live-status`：它返回键盘连接、窗口数量、预览缓存和物理内存等状态，不返回窗口标题、截图或用户输入。

本机专项演练可在退出程序后使用 `open /Applications/CtrlSwitch.app --args --exercise-switcher`，显示真实面板并执行 500 次选择变化，结果通过 `--live-status` 查看。它不发送全局模拟按键，也不替用户激活窗口；不能替代真实键盘的切换验证。
