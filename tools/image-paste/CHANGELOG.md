# 更新记录

## 1.3.0

- 托盘增加“检查更新”，只匹配图片直粘的正式版本和 Windows x64 安装包。
- 支持跨页检查、数字版本比较、超时提示；有新版可打开官方发布页下载。
- 手动检查，不后台轮询，不自动安装或替换程序。

## 1.2.0

- 图片处理期间显示 Windows 系统忙碌光标，完成或失败后恢复。
- 独立恢复进程在主程序意外退出时恢复原有光标。
- 移除鼠标旁的额外状态提示框。

## 1.1.0

- 增加鼠标旁读取、转换、保存及结果提示；该方案已在 1.2.0 移除。

## 1.0.0

- 首次提供桌面及资源管理器 Ctrl + V 图片保存功能。
- 支持 PNG、DIB/DIBV5 和 Bitmap，保留常见透明图片。
- 托盘常驻、暂停、可选开机启动和不覆盖文件的命名。
