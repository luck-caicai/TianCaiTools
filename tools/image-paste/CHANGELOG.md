# 更新记录

## 1.3.2

- 兼容腾讯桌面整理（DeskGo）的 TXMiniSkin 桌面窗口，图片直接保存到系统实际桌面目录。
- 仅接管 DesktopMgr/ DesktopMgr64 的完整桌面背景且焦点位于背景时的粘贴，排除子编辑框、菜单及较小面板。
- 修正 1.3.1 仅处理原生桌面、未覆盖腾讯桌面整理导致仍无反应的问题。

## 1.3.1

- 修复桌面宿主获得焦点、或显示桌面后没有子控件焦点时，图片 Ctrl + V 未被识别的问题。
- 支持 Progman 与 WorkerW 分离的桌面图标视图，校验桌面宿主属于系统 Shell。
- 不再把光标闪烁状态当作禁止粘贴；菜单、重命名及非桌面窗口仍不接管。

## 1.3.0

- 托盘增加“工具所在位置”，打开文件夹并选中当前运行的 EXE。
- 托盘增加“检查更新”，只匹配图片直粘的正式版本和 Windows x64 安装包。
- 支持跨页检查、数字版本比较、超时提示；有新版可打开官方发布页下载。
- 手动检查，不后台轮询，不自动安装或替换程序。

## 1.2.0

- 图片处理期间显示 Windows 系统忙碌光标，完成或失败后恢复。
- 独立恢复进程在主程序意外退出时恢复原有光标。
- 移除鼠标旁的额外状态提示框。

## 1.1.0

- 增加鼠标旁读取、转换、保存及结果提示；该方案已在 1.2.0 移除。

## 1.0.0

- 首次提供桌面及资源管理器 Ctrl + V 图片保存功能。
- 支持 PNG、DIB/DIBV5 和 Bitmap，保留常见透明图片。
- 托盘常驻、暂停、可选开机启动和不覆盖文件的命名。
